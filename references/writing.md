# 文案

无旁白片子的全部内容，都在字幕里。所以文案就是剧本。

## 一条总规则

> **每一句里，至少有一个能想象的画面或动作。**

写完逐句自检：这句能不能拍成画面？不能就重写。

---

## 五条具体手法

### 1. 两个节拍

他的句子几乎都是「前半句给画面，后半句给判断」，中间一个逗号：

```
领奖台上，第二名笑不出来。
铜牌嘴里，更多是"至少"。
爽完之后，会跌到基线以下。
平常的快乐，都没了味道。
```

一句话里两个动作：先让你看见，再告诉你。

### 2. 具体名词压过抽象名词

| 抽象 | 具体 |
|---|---|
| 答案的长短和记忆数量高度相关 | 有人记得三件，有人记得八件 |
| 记忆细节不起作用 | 至于他穿什么颜色——没人记得 |
| 时间感知被压缩 | 可它一秒钟，都没有少 |

数字也要换成能看见的：不说「效应量 12.23 秒」，说「每多一件，答案就长出十二秒」。

### 3. 动词要狠

一个动词决定一句话的生死。

```
多 12 秒   →  长出十二秒      （长出：有生命、有延展）
重复前一天 →  复印前一天      （复印：有磨损、越印越淡）
求更多时间 →  求更多第一次    （求：求而不得）
```

### 4. 破折号悬念 + 短句回收

```
至于他穿什么颜色——
没人记得。
也不影响答案。
```

话说到一半收住，用句号把下一句切到极短，再补一句钉死论点。**停顿本身就是内容。**

### 5. 结尾落在动作或问句，不给建议

| 弱 | 强 |
|---|---|
| 去做一件没做过的事 | 今年，还剩多少天？ |
| 我们应该珍惜当下 | 挑一天，做一件没做过的事 |
| 所以要保持好奇心 | 不为体验。为了让这一年，长一点。 |

建议是布置作业，问句是把决定权交回去。

## 数据对照

来自同类型作品的字幕数据与自写对比：

| 指标 | 参考 | 自写第一版 | 自写终版 |
|---|---|---|---|
| 平均句长 | 20.9 字 | 13.0 字 | ~13 字 |
| 每句逗号 | 1.33 | 0.74 | 0.88 |
| 句号/千字 | 42.3 | 69.0 | 70.6 |
| 每秒字数 | 3.09 | 2.64 | 2.46 |

**注意**：参考值的平均句长被 OCR 虚高（两行常被合并），不要硬追这个数字。真正要追的是「每句一个画面」。

## 禁用词

出现即改：

```
高度相关 · 起到作用 · 机制 · 维度 · 层面 · 某种程度
显著 · 呈现 · 体现 · 反映 · 表明 · 意味着
值得注意 · 不难发现 · 可以说 · 事实上
```

替换方向：换成一个人、一个动作、一个数字。

## 冷开场模板

前三秒决定去留。三种开法：

**A. 问—答—反证**（最稳）
```
去年今天，你在做什么？
想不起来了。
可它一秒钟，都没有少。
```

**B. 场景直给**
```
领奖台上，第二名笑不出来。
```

**C. 数字冲击**
```
这句「我爱你」，你已经说了 1000 遍。
它现在带来的信息量，几乎是零。
```

三种都要在 12 秒内进入正题。不要在开场堆背景。

## 写完之后

1. 逐句问「能不能拍成画面」，不能的重写。
2. 数一数有几处「你」。超过每千字 10 次就腻了。
3. 把最后一句单独念一遍。不像格言就重写。
4. 从头念一遍，计时。超过 165 秒就删句子，别删停顿。
