# 画面

## 五条摄影原则

一条片子从"卡片切换"变成"电影"，靠的是这五条。

### 1. 满

画面要**溢出边框**，不出现完整的矩形。

- ✗ 一张居中的卡片，四周留黑
- ✓ 一千个格子铺满画面，四边切掉

实现：让元素的实际尺寸大于画幅，靠 `scale` 居中溢出。

### 2. 推

相机**全片都在动**，哪怕只有 4%。

```ts
const push = 1 + 0.05 * at(t, 0, 18);  // 18 秒推 5%，看不出来但画面不死
```

每一幕各自给一个推速，幕尾加速离场。

### 3. 空气

加尘埃。60–70 颗粒子，缓慢上浮，每颗有自己的速度与呼吸相位。

```ts
cy={p.y - ((t * p.v) % (H + 120)) + 60}
opacity={p.a * (0.45 + 0.55 * Math.sin(t * 0.9 + p.ph) ** 2)}
```

没有尘埃，画面是真空；有了尘埃，才有空间。

### 4. 人

至少一个背影或一只手。抽象图形再美也是冷的。

一个剪影 + 呼吸就够了：

```ts
const br = 1 + 0.006 * Math.sin((2 * Math.PI * t) / 5.2);
```

5.2 秒一个呼吸周期。同时把配乐的低频本体也按 5.2 秒做振幅调制——画面和声音，同一个肺。

位置：横版左下、竖版右下，脚出画，只留头肩。**不要居中**，居中会挡住主体。

### 5. 光

三层叠加，缺一不可：

| 层 | 做法 | 作用 |
|---|---|---|
| 色温 | 开头暖 → 中段冷 → 结尾回暖 | 观众说不出，但身体知道 |
| 暗角 | 径向渐变，边缘压到 0.9 黑 | 把视线收到中心 |
| 颗粒 | grain.png 叠加，overlay 16% | 去掉数码感 |

## 两个镜头运动

### 坠入（约 18 秒）

幕末 1.4 秒内倍率从 1.05 冲到 2.4，同时溶解进下一幕。

```ts
const dive = 1 + 1.4 * at(t, 17.6, 19.0);
```

配乐同步：这里必须**全静音 0.9 秒**，然后一个低频 boom 落地。

### 退回（约 124 秒）

从 1.45 倍（贴着细节）在 9 秒内退回 1.0 倍，露出全景。

```ts
const pullBack = 1 + 0.45 * (1 - at(t, 124.0, 133.0));
```

## 一个「时刻」

全片只允许有一处让人屏息的画面。通常是：

- 大量同类元素**同时熄灭**，只剩几个
- 或者**同时亮起**

例：365 格熄灭到只剩 9 格，那 9 格带光晕浮在尘埃里，像夜空里的星。

这个镜头要提前设计，全片所有其他镜头都为它让路。

## 字幕可读性

**字幕永远压在画面上，所以永远需要暗底。**

```tsx
<div style={{
  position: "absolute", left: "50%", bottom: 86,
  width: 1560, height: 250, transform: "translateX(-50%)",
  background: "radial-gradient(ellipse closest-side, rgba(0,0,0,0.78) 0%, rgba(0,0,0,0.45) 50%, rgba(0,0,0,0) 82%)",
  filter: "blur(10px)",
}} />
```

暗场里看不见，亮场里救命。

## 场景组件清单

五幕各有一个可复用场景，都在 `assets/YearWorld.tsx`：

| 组件 | 用途 | 关键参数 |
|---|---|---|
| `Calendar` | 全景墙（天数、条目、列表） | `mode: decay \| rekindle`、`push` |
| `Ratio` | 两根等高柱（比例对比） | 每根柱的格数 `n` |
| `Segments` | 横条被切分（过程拆解） | `ticks` 时间点数组 |
| `Road` | 消失点透视（行进、时间流逝） | `passes` 走过次数 |
| `Figure` | 背影剪影 | `x`、`o`、`s` |

换题时优先改数据，不要重写组件。
