# 封面与标题

## 封面铁律

> **母题必须来自片中最重要的那一个画面。**

不要另起一套视觉。观众看完片子，再看到封面，要能对上号。

| 集 | 片中母题 | 封面母题 |
|---|---|---|
| 命运 | 星盘环 | 一圈星盘 + 中心一点光 |
| 记忆 | 头骨 + 神经 | 侧脸轮廓 + 金色神经路径 |
| 录音 | 骨传导路径 | 头骨 + 一条从喉咙到耳蜗的线 |
| 目标 | 身份卡 | 一张盖了「已认证」的卡 |
| 时间 | 全景墙 + 背影 | 一千格墙 + 九格亮 + 一个背影 |

## 三个尺寸，一次出

| 尺寸 | 分辨率 | 平台 |
|---|---|---|
| 16:9 | 1920×1080 | B站、公众号 |
| 9:16 | 1080×1920 | 抖音、快手 |
| 3:4 | 1080×1440 | **小红书** |

用同一个组件，靠 `vertical` 判断排布差异：
- 16:9：人物左下，标题横贯
- 9:16：人物右下，标题两行
- 3:4：人物右下，标题两行，底部多一行角标

**永远三个一起出。** 发的时候才知道用哪个。

## 封面文字层

四层信息，从大到小：

```
顶部      EP.05 · 记忆怎么改写时间          ← 系列归属
主标题    你的这一年，只有七八天             ← 一句话断言
副标题    不是时间变快，是你没留下痕迹        ← 机制或反转
底部角标  2026 新研究 · 事件边界 · +12 秒    ← 只在竖版出现
```

主标题里**只有关键词染色**，其余留白。一句话里只有几个字发光，视线才会停。

## 主标题怎么选

**不要用片名。** 片名是解释，封面要的是让人愣一下。

| 片名 | 封面标题 |
|---|---|
| 为什么长大后，一年比一年短 | 你的这一年，只有七八天 |
| 为什么说出来的目标更难实现 | 说出去的目标，为什么更难实现 |
| 为什么你听自己的录音那么难听 | 你从没听过，别人听到的你 |

原则：
1. **优先陈述句，不用问句。** 问句要观众先启动思考，陈述句直接给结果。
2. **数字可以模糊。** 「七八天」像经验，「8.7 天」像论文。
3. **不解释原因。** 原因留给片子。

## 三平台文案

同一条片子，三扇不同的门。

| | 抖音 | B站 | 小红书 |
|---|---|---|---|
| 封面 | 9:16 | 16:9 | 3:4 |
| 标题长度 | 露出 1.5 行 | 带「｜」，要能被搜到 | **≤20 字** |
| 语气 | 挑衅、断言 | 讲述、给信息 | **第一人称分享** |
| 正文 | 3–4 行 | 简介 100 字 | **300–800 字，分段** |
| 最看重 | 完播、点赞 | 投币、收藏 | **收藏率** |
| 用户要什么 | 被刺激一下 | 学到东西 | "我也能用" |

### 抖音

```
你的这一年，只有七八天。

不是时间变快了。
是你把三百六十五天，过成了同一天。

#认知科学 #时间感知 #冷知识
```

第一行必须是断言。信息流只露出 1.5 行。

### B站

```
你的这一年，只有七八天｜2026年新研究：记忆是怎么改写时间的
```

前半钩子，后半可搜。关键词短语要完整出现。

### 小红书

标题 ≤20 字，正文 300–800 字，第一人称，分段，末尾给可执行的三件事。

**关键差异：小红书要"结论前置"。** 抖音能容忍悬念开场，小红书前三秒不出结论就被划走。发小红书时做一个 3 秒特供开头：

```
0–1s  黑场：一年 365 天
1–2s  第二行：你只记得 8 天
2–3s  切正片第一帧
```

抖音走「悬念—揭晓」，小红书走「结论—解释」。

## 五类标题钩子

| 类型 | 例 | 适合 |
|---|---|---|
| 反常识断言 | 你的这一年，只有七八天 | 抖音、小红书 |
| 归因翻转 | 时间没有变快，是你把一年过成了一天 | 评论区容易吵 |
| 直接提问 | 为什么长大后一年比一年短 | B站搜索 |
| 数字 + 权威 | 2026年新研究：每多记一件事，一年长12秒 | 知识区、知乎 |
| 冒犯感 | 你记得住的，不到十天 | 争议最大 |

主推选**反常识断言**：不是问句，不解释原因，数字模糊。
