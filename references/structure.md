# 结构

固定 161 秒。不是美学选择，是因为这个长度下完播率和信息量比值最高。

## 六幕时间轴

| 幕 | 时间 | 内容 | 画面要求 |
|---|---|---|---|
| 一 | 0–18s | 冷开场：一个具体画面 + 一个反证 | 满屏、有空气、有人 |
| 二 | 18–43s | 流行解释：先立后破 | 几何、冷静、无温度 |
| 三 | 43–76s | 实验：具体的人 + 具体数字 | 机械、有刻度、有反馈 |
| 四 | 76–124s | 机制：一路讲到底 | 有纵深、有行进感 |
| 五 | 124–152s | 落点：回到开头的画面 | 回望、暗下来 |
| 六 | 152–158s | 收尾：一句，然后静 | 只剩一个光点 |

158–161 秒进片尾卡。片尾卡不占用叙事时间。

## 节奏参数

```
字幕条数     30 ± 4
总字数       ~400 字
每秒字数     2.4–3.1
单条停留     4.5–5.0s（最短不低于 2.0s）
首句长度     ≤12 字
```

**宁可少说一句，不要说得更快。** 2.4 字/秒是下限；超过 3.2 就开始像念稿。

## 三处必须留白

1. **18 秒的镜头运动**——一句话说完，画面自己走 1 秒。
2. **76 秒的换场**——机制段换世界，不打断解说。
3. **152 秒之后**——最后一句说完，留 3 秒只有画面和余音。

留白不是空，是让上一句落地。

## 幕间转场

全部溶解，1.0 秒。两种例外：

- **坠入**（18 秒）：镜头加速推入上一幕，2.4 倍，边推边溶解。
- **退回**（124 秒）：从贴着细节的特写开始，缓慢拉远 12 秒，露出全景。

这两个是全片唯一的"镜头说话"，一进一出，把片子框住。

## 时间轴怎么写

用「秒」写死，不要用帧：

```ts
const SUBS = [
  { a: 0.8, b: 4.4, text: "去年今天，你在做什么？" },
  { a: 4.8, b: 7.2, text: "想不起来了。" },
  ...
]
```

规则：
- 每句之间留 **0.4s** 空隙（上一句淡出 + 下一句淡入）
- 短句（≤6 字）给 2.4–3.0s
- 长句（≥16 字）给 4.5–5.5s
- 关键词用 `hi` 标注，渲染时自动换色

## 片尾卡

必须包含：
1. 完整学术引用（作者、年份、标题、期刊、卷期页）
2. 核心数字的出处（哪一组、样本量）
3. 三条边界说明（这个结论在什么条件下不成立）

没有这三样，片子就是营销不是科普。
