# 声音

配乐不是铺底，是**事件表**。

## 一条原则

> 每一处画面转折，都要有一个声音事件对应。

如果配乐从头到尾是同一层 pad，画面再精彩也像配了乐 PPT。

---

## 事件表

一条 161 秒的片子，至少需要这些事件：

| 时间 | 事件 | 声音 | 目的 |
|---|---|---|---|
| 15.6–17.6 | 起势 | 噪声从 80Hz 扫到 1500Hz | 让身体预感要发生什么 |
| **17.6–19.0** | **坠落** | **全轨压到 −36 dB，只剩一道 2600→140Hz 的风** | **最强的刀** |
| 19.0 | 落地 | 低频 boom（74→28Hz） | 释放 |
| 每处递增 | 刻度 | 短促 tick，音高递增 | 让"又多了一个"被听见 |
| 行进段 | 步伐 | 极轻的 58Hz 闷击，每 6.5s 一次 | 空间移动感 |
| 末句 | 收束 | 一个单音，5 秒衰减 | 让最后的画面落地 |

---

## 静音是最强的手法

在关键转场处，把整条音轨压下去。

```python
duck[a:b] = np.linspace(1.0, 0.16, b - a)   # 起势时抽走
duck[b:c] = 0.02                             # 坠落：几乎全静
duck[c:d] = np.linspace(0.02, 1.0, d - c)**1.6  # 落地后慢慢回来
```

实测效果：18.5 秒处整轨 −36.7 dB，比正常低 18 dB，持续 0.9 秒。

观众的耳朵会"空一下"，然后 boom 落地。这一下比任何音效都响。

**只在全片用一次。** 用两次就不灵了。

---

## 与人同呼吸

画面的剪影用 5.2 秒周期呼吸。配乐的低频本体也用同一个周期：

```python
breath = 0.86 + 0.14 * np.sin(2 * np.pi * tt / 5.2)
music.add(drone * swell * breath, 0.0, 0.05)
```

两条曲线相位不同没关系，周期必须相同。观众不会发现，但会觉得"这个画面是活的"。

---

## 电平

```
平均     −20 至 −22 dBFS
峰值     ≤ −4.5 dBFS
```

静音段落可以到 −36，但**全片平均**要保持在 −20 左右。太低会在手机外放时消失。

## 实现

`assets/score_episode.py` 是模板。改这几处即可：

```python
DUR = 161.0                 # 与成片等长
SECTIONS = [...]            # 每段的 pad/piano/kick 电平
TICKS = [...]               # 刻度出现的时间点
DIVE_IN, DIVE_OUT = 17.6, 19.0
LAST = 156.4                # 最后一个音
```

生成后必须验证包络：

```powershell
python -c "..."   # 逐秒算 RMS，确认静音段真的静了
```

不要凭感觉，看数字。
